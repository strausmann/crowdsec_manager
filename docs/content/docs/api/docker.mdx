# Docker API

> **Warning:** This page is under revision. Some endpoints may be incorrect. The actual API uses grouped route prefixes (`/api/services`, `/api/update`, `/api/hosts`) rather than a flat `/api/docker` namespace. Refer to `internal/api/routes.go` for the authoritative endpoint list.

## Service Management

- `GET /api/services/verify` — Verify running services against expected configuration.
- `POST /api/services/shutdown` — Graceful shutdown of managed services.
- `POST /api/services/action` — Perform an action (start, stop, restart) on a service.

## Update Endpoints

- `GET /api/update/check` — Check for available image updates.
- `POST /api/update/with-crowdsec` — Apply updates including the CrowdSec container.
- `POST /api/update/without-crowdsec` — Apply updates excluding the CrowdSec container.

## Docker Hosts

- `GET /api/hosts/list` — List configured Docker hosts (multi-host mode).
